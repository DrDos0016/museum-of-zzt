I'm stuck in the world I'm playing!

Depending on how you're stuck, you may want to try the following:

  • A lack of health or other resources: Press ? to open the cheat prompt and use the appropriate cheat listed on the ZZT Cheats page.
  • The player is surrounded and unable to move: Press ? to open the cheat prompt and enter ZAP to erase the four tiles surrounding the player.
  • The player has been destroyed: Oops. Hope you saved. This typically happens due to a bug with how conveyors work.
  • The game is paused and the player can't move to unpause: Moving is the only way for ZZT to unpause your game.It's best to use ESCAPE as a pause method instead. Keep in mind that the game starts paused as well, so saving while surrounded (something easy to do with engine based games like ZZT platformers) will result in a save that can't be played when restored. For a broken save, changing the configuration to use SolidHUD may allow you recover by pressing P to unpause.
  • It's unclear where to go next: Try looking for some information in the file's feedback or associated articles. A small number of files have had full walkthroughs written for them or author created guidance included in the world's documentation. You can also use the file viewer to explore the world freely.
  • I need some item, but don't know where to find it: Use the file viewer! Click on objects to view their code and look for things like #IF CROWBAR ESCAPE. Then use the ZZT-OOP Search in the World tab to look for #SET CROWBAR to find where the item is acquired. If the item is one of ZZT's built-in keys, search for <COLOR> KEY to find objects that place keys on the board or transform into one.
  • An Impromptu Quiz™ has me stumped: Use the editor or file viewer to look up the answers in the object's code. You'll find code simliar to !w;Wrong Answer and !r;Right Answer. The text before the semicolon indicates which label (:w or :r) the object will jump to after selecting a choice. Use these labels to identify correct answers.
  • A maze in hindering my progress: The file viewer can help reveal some hidden tiles more easily. Under the preferences tab try out other board rendering methods to reveal fake walls or empties.

Pressing P to play results in a DOS Error message!

This is caused either by ZZT or Zeta not correctly pointing to the proper world. This most frequently happens with games that require non-default Zeta configurations or worlds whose filenames doen't match the names stored within the file itself used by ZZT. Try pressing ENTER to close the message. Then press W to open the world menu, and manually select the proper world.

Pressing E to edit a world results in a red flash and a can not edit world/save message!

The world you tried to edit has been LOCKED which prevent players from easily editing a world. These locks can all be circumvented easily.

From within the editor hit ? to open the cheat prompt and enter +DEBUG. Reload the world with L and the world should open just fine. Enter -DEBUG at the cheat prompt to unset the debug flag, which can cause issues if left set during gameplay. More about Locks

The editor's board list is showing boards named ►LOCKED FILE or similar which do not open properly!

The world you're editing is (also) Super Locked. You can open the locked boards by hitting Escape instead of Enter. The :c board is a deliberately corrupt board which designed to crash ZZT's editor. More about Locks
