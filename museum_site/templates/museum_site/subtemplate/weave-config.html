Key Binds

# This can be a single character: # input.1.keybind = "A" # Or a single character followed by a display string encased in single quotes: # input.1.keybind = " ,'SPACE'" input.1.keybind = "" # The message to send. This is the label sent to # your Input Terminal (above) upon pressing the # key. Maximum length: 12 characters.) input.1.label = "" # The row to populate in the sidebar. (Set # to 0 to not show the keybind in the sidebar. # This is a string value, so keep the quotes.) input.1.sidebar.row = "0"

Key is the character pressed. Name is an alternate string to display in the sidebar. Label is the label @INPUT is sent to upon pressing the key. Sidebar row is the position in the sidebar to inform users of the key. Set to 0 to not display. Only key and label need to be specified for a key bind to work.
